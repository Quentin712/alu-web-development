## 📖 How to Use These Images

### In HTML (img tag)
```html
<img src="https://html-homework-assets.vercel.app/logo.svg" alt="Logo">
```

### In CSS (background image)
```css
body {
  background-image: url('https://html-homework-assets.vercel.app/bg.jpg');
}
```

### Important Notes
- These URLs use GitHub's **raw content delivery**, which works perfectly for CodePen and other online editors
- No authentication required - these files are from a public repository
- Replace `logo.svg` with any filename from the table above
- The format works for all file types: `.jpg`, `.png`, `.svg`

### Tips for CodePen
1. Copy any URL from the "Copy-Paste Friendly URL" column above
2. Paste it directly into your `<img>` tag's `src` attribute or CSS's `url()` function
3. You can now use unlimited images without hitting CodePen's file upload limit!
