My Journey into Web Development

I started learning HTML because every real web project needs a solid structure before anything else makes sense, no CSS, no JavaScript framework, none of it means anything without valid markup underneath.

Why I'm doing this

I'm a first year BSE student focused on using technology to solve real problems, particularly around youth employment and agriculture. Web development is one of the foundational skills that makes that possible.

What I've learned so far

The biggest lesson has been that "basic" html is not the same as "sloppy" html. The W3C validator does not care how the page looks, it cares whether the markup is correct, and that discipline carries over into everything else.
